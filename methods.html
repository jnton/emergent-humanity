Models, evidence, and limits

The animated essay uses the original visual illustrations. These notes describe the separate quantitative model lab.

These are inspectable toy models and illustrations. They do not establish that a mechanism dominates real societies. Mathematical, empirical, interpretive, and normative claims are different kinds of claims.

The models are deterministic for a fixed seed and sequence of actions. Default seed: 74291. Run advances a fixed logical step every 300 ms; Step advances once. Drawing size and display refresh rate do not affect scientific state. There is no human flourishing score.

Review status: local implementation checks are distinct from independent specialist review, which is still pending. Source access limitations are listed below.

03 — The Limits of a Node

Claim type

Assumptions

    05 — A Tiny Difference

    Claim type
    Discrete dynamical model
    Assumptions
    Twenty-four nodes on a ring; two identical initial states; one perturbation of 10⁻⁷.
    Parameters and intervention
    Averaging weights .62/.38; nonlinear logistic parameter 3.9, coupling .08.
    What this does not establish
    The averaging consensus mode preserves an offset; finite-time separation is not a maximal Lyapunov exponent.

    Update rule / observable (plain-text mathematical notation):

    averaging: xᵢ′=.62xᵢ+.38 mean(neighbors)
sensitive: f(x)=3.9x(1−x); xᵢ′=.92f(xᵢ)+.08 mean(f(neighbors))
gₜ=log(maxᵢ|aᵢ−bᵢ|/10⁻⁷)/t

      07 — Closing the Distance

      08 — When Information Fails

      Claim type
      Layered toy experiment
      Assumptions
      Binary world state is fixed at 1. Source truth, channel fidelity and interpretation are separate.
      Parameters and intervention
      Bernoulli channel fidelity; optional inversion; adversarial selection repeats only errors.
      What this does not establish
      Real semantics, trust, and incentives are not binary switches; trial totals mix settings if controls change.

      Update rule / observable (plain-text mathematical notation):

      source → channel flip with probability 1−q → optional interpretation inversion → selection

      09 — The Network Splits

      Claim type
      Bounded-confidence toy model
      Assumptions
      Forty seeded opinions, uniform over [−1,1]. Random pair encounters use simultaneous symmetric updates.
      Parameters and intervention
      μ=.12; ε=1.85−1.7×selectivity. Trusted mode waives ε for three agents.
      What this does not establish
      The histogram concerns opinions, not hostility or all mechanisms of political polarization.

      Update rule / observable (plain-text mathematical notation):

      if |oᵢ−oⱼ|≤ε: oᵢ′=oᵢ+.12(oⱼ−oᵢ); oⱼ′=oⱼ−.12(oⱼ−oᵢ)

      Implementation checked locally; independent specialist review pending.

      • Deffuant et al. (2000), Mixing beliefs among interacting agents

        Bounded-confidence family; this project exposes its own update rule explicitly. Publisher access blocked during audit; exact model attribution review pending.

      • Bail et al. (2018), Exposure to opposing views on social media can increase political polarization

        A particular US Twitter intervention increased polarization among Republican participants; Democratic effect was not significant. Not a universal contact law. Study summary and publisher text consulted in audit.

      11 — Touching Reality

      Claim type
      Estimation model
      Assumptions
      Target 50; independent uniform measurement noise over [−15,15]; optional +15 bias.
      Parameters and intervention
      Take a new measurement or repeat the previous value.
      What this does not establish
      Repeated samples reweight the arithmetic mean; no confidence interval falsely treats them as independent.

      12 — Memory Beyond the Individual

      Claim type
      Replication model
      Assumptions
      Twelve-node ring. Each carrier copies to at most one available neighboring recipient per step.
      Parameters and intervention
      Mutation off by default; if on, 8% chance of incrementing a variant at each copy (illustrative).
      What this does not establish
      Copying is instantaneous at logical steps; no forgetting or in-flight storage is modeled. Exact copying does not establish truth.

      Update rule / observable (plain-text mathematical notation):

      lineage survives if live copy count > 0
exact fidelity counts variant 0 only

          14 — Against Noise

          Claim type
          Binary symmetric channel
          Assumptions
          Three identical independent hops; twelve bits; one or five copies; per-run settings frozen.
          Parameters and intervention
          Bit-flip p in [0,.15]. Shared-error mode uses the same flip mask across all copies per hop.
          What this does not establish
          Majority benefit assumes independent copies. Expected bit error is not whole-message error or semantic correctness.

          pₕ = [1−(1−2p)ʰ]/2
P₅ = 10pₕ³(1−pₕ)² + 5pₕ⁴(1−pₕ) + pₕ⁵

          17 — How Humanity Thrives

          Claim type
          Constrained graph comparison + normative reflection

          What this does not establish
          Frontier is among nine sampled designs for these two objectives. It does not establish fairness or the full Pareto frontier.

          Update rule / observable (plain-text mathematical notation):

          cost = installed links; service = delivered requests / 11
